# 神罚 v2 推翻重构 · 执行计划（Implementation Plan）

> 设计依据：`docs/superpowers/specs/2026-10-25-v2-rewrite-design.md`（先行阅读）。
> 分支：`feat/v2`（自 main 942fe63 起）。每个 M 结束跑 `npm run typecheck && npm test` 并 codelog 留痕；提交信息中文、一次一件事；M 完成给提交建议等确认。

**Goal:** 推翻 v1 底盘（存储/导航/状态/自动记账），以 Expo 54 + Expo Router + Zustand + expo-sqlite/drizzle 重写为 v2，保留 core 资产与产品哲学，发布 1.0.0。

**验证口径:** 每任务：typecheck + jest；每 M：真机 dev build 冒烟 + Maestro 截图（M1 起配）。

## M1 v2 骨架（Est: 2 天）

- [ ] 升级 Expo 52 → **SDK 57**（`npx expo install expo@^57 --fix`，SDK 57 无破坏性变更；注意 prebuild 默认 clean，android/ 重新生成；务必升到 57.0.9+ 修 Hermes 内存回归），单独提交，真机验证 v1 功能不回归
- [ ] 安全基线 P0 先行：app.json `useSQLCipher` + `PRAGMA key`/`cipher_version` 自检、`allowBackup=false` + dataExtractionRules、MMKV 引入 `src/lib/kv.ts`
- [ ] 引入 expo-router：`app/_layout.tsx` + `app/(tabs)/`（home/ledger/debts/goals/me 五占位页），删除假 tab 逻辑；deep link scheme 验证
- [ ] 引入 expo-sqlite + drizzle-orm + drizzle-kit：`src/db/schema.ts`（按 spec §4 全表）、首次迁移生成、`client.ts`（SQLiteProvider + useMigrations + PRAGMA 前置）、Metro asset 打包迁移验证
- [ ] Zustand：`src/features/settings/store.ts`（第一个样板 store）+ selectors 约定注释
- [ ] 主题迁移：tokens 不动，`useThemedStyles` 挂进新 Provider 链；三档切换冒烟
