# 严格型个人记账 App 第一版设计

## 目标

构建一个 Android 优先的个人记账 MVP，围绕“今天还能花多少、未来能否按时还款、存钱目标是否会延期”形成闭环。

## 第一版范围

- 极简快速记账：支出、收入、转账；
- 首页、账本、待还、目标、我的五个界面；
- 本地持久化交易、目标、欠账和设置；
- 今日可花金额、本月还需存、未来待还和现金流风险计算；
- 记账后的 B 平衡提醒弹窗；
- 现金流风险卡片三档显示：始终显示、仅风险时显示、首页隐藏；
- 独立日志模块，日志可查看和清空；
- 银行/支付/Root 能力只提供适配器接口和状态占位，不在 MVP 中绕过系统安全边界。

## 非目标

- 不发起支付、转账或修改银行数据；
- 不把 Root 作为主 App 运行前提；
- 不读取短信或保存银行密码；
- 不在第一版接入真实银行聚合服务；
- 不提供投资、家庭共享和复杂 AI 顾问功能。

## 架构

采用 Expo + React Native + TypeScript。`src/core` 放纯业务模型、计算和日志；`src/data` 负责本地存储；`src/integrations` 负责银行、通知和 Root 的可替换接口；`src/features` 只组织页面和交互；`app` 仅负责路由入口。UI 不直接访问 AsyncStorage，业务计算不依赖 React。

## 核心规则

- 现金流风险默认“仅风险时显示”；
- 记账后的默认提醒是 B 平衡提醒，只提醒不阻止；
- 消费、还款和账户转账必须区分；
- 目标计划以剩余目标、截止日期、收入、工作天数和固定支出为输入；
- 日志必须脱敏，不记录 token、密码、完整卡号或原始通知全文；
- 主题色通过 token 管理，第一版使用中性灰，后续可独立换肤。
