## 1. 产品定位

**一句话**：一个纯粹、好用、好看的记账本——打开就看到账，点一下就知道钱花哪了，剩下的钱一眼清楚。

与神罚版（0.9.0 及以前）的分野：

| 维度 | 神罚版 | 2.0 |
| --- | --- | --- |
| 核心 | 控制可花额度（工时折算惩罚） | 纯粹记账 + 账户余额 |
| 首页主角 | 今日可花 / 神罚效果 | 总余额大数字 + 流水 |
| 记账姿势 | 自动检测为主 | 完整表单认真记 |
| 情绪 | 惩罚感、紧张感 | 中性、清爽、好看 |

## 2. 需求决策（46 项）

### A. 定位（8 项）

1. **力度：全盘推倒重来**，不是换皮。旧页面、旧交互、旧视觉全部重做。
2. **神罚整套拿掉**：工时折算、惩罚评估（极罚/重罚/警告）、预算平衡提醒、今日可花 hero，全部删除。重新想 App 到底要干什么，答案是：记账本。
3. **首页形态：两种合一**——「打开就是账」（清爽账本）+「打开就是我花到哪了」（钱去哪、剩多少），两者不冲突、是一对。
4. **主次：先见账，再看花哪了**。首页先见账本（本月花了多少 + 流水），"花到哪了"（分类占比 / 该省哪）点进统计页才看到。
5. **记账对象：支出为主、收入次之**。吃饭、打车、买东西是主力；工资等收入偶尔记。
6. **转账要支持**（改判早期"转账基本不碰"）：钱从银行卡转微信，总数不变、位置变了，不记这笔则两边账户余额都漂。转账是余额准确的必要条件，不是可选功能。
7. **每笔挂账户**：记支出 / 收入时多一步"从哪出 / 进哪"，余额才能自动滚。
8. **记账入口：完整表单**。金额、分类、账户、备注、日期一次填全。准确优先于速度——认真记，不搞"3 秒极速记"。

### B. 余额与账户（6 项）

9. **余额语义：账户级余额**。微信、支付宝、银行卡各剩多少，与"这个月"无关，是当下这个瞬间。
10. **余额维护：流水自动算**。每个账户给一个初始余额，之后余额 = 初始 + 收入 − 支出，永不手改余额（改余额只能通过改流水实现）。
11. **默认账户：微信、支付宝、银行卡**三个，首次安装即就位。
12. **初始余额：开记时手动填一次**。首次打开 App 引导填写每个账户"现在大概有多少"，之后全靠流水滚。
13. **账户可新增**：能加第四个、第五个（信用卡、现金钱包等），默认三个不变。
14. **账户删除：能停用，删除只对空账户开放**。停用的账户藏起来但流水还在（历史统计不受影响）；删除仅限从未记过账的账户。

### C. 分类（4 项）

15. **支出分类：两级，大类套小类**。如「购物」下分「衣服 / 数码 / 家居」，「吃饭」下分「早午晚 / 外卖 / 聚餐」。洞察能下钻，记账时多选一层。
16. **收入分类：要分，但少**。工资 / 副业 / 报销 / 其他，三四类够。收入只一级、不套小类。
17. **分类完全自由改**：默认那套只是起点，随时增删改分类、加小类、改图标、换颜色，两级结构随你建。
18. **删分类 → 流水落「未分类」**：删除分类后，挂在它下面的旧流水落进「未分类」，统计里单列，后续可手动重新分类。

### D. 流水操作（3 项）

19. **改错：字段随便改**。点开流水直接改金额 / 分类 / 账户 / 日期 / 备注，改完余额自动重算。
20. **删除：二次确认**。删除整笔流水要点两次确认，防手滑把真账删了。
21. **补记：日期随便选**。今天、昨天、上个月都能记。流水按日期回看，月统计认"过去那天的账"。

### E. 首页界面（6 项）

22. **顶部余额卡**：最大数字是**总余额**；本月支出缩成小字；**今日支出**也要一眼看到。
23. **洞察入口：余额卡右下角「统计」小图标**，点进独立统计页。首页保持纯账本，洞察藏得干净。
24. **流水分组：按天分组 + 折叠**。每天一个日期头，今天默认展开；非今天的日期默认折叠成一行"11月15日 · 支出 ¥86"，点开才展开明细。
25. **流水行显示：默认简洁 + 三开关**。出厂默认：分类图标 + 备注 + 金额。备注 / 账户 / 分类名三个字段各自一个开关，设置在「流水显示」里实时预览调整。
26. **默认位置：今天优先 + 快速跳转**。打开停今天；顶部日期头可点，侧边日期跳转条可跳。
27. **记账入口：右下角圆形悬浮 `+`**。拇指区，单手持机最顺手，点一下直接弹记账表单。

### F. 视觉（3 项）

28. **风格：暗色质感**。深色底、高对比、霓虹点缀，晚上记账不刺眼，科技感。
29. **主题：默认暗色 + 可选浅色**。出厂暗色；设置里给「浅色模式」开关，两套配色都维护。
30. **主色：暖橙 / 琥珀**。暗底上的暖色点缀，有温度。

### G. 动画（4 项）

31. **分量：处处都有**。按钮按下有弹性、列表滚动有阻尼、分组折叠有展开动画、统计图有生长动画。
32. **记账成功动效：三档可选**（设置里选）：
    - **清爽回位**：表单收起、新流水从顶部滑入、余额数字滚动更新，干净利落。
    - **轻快收束**：点保存后表单"咻"地收成一个点飞向流水列表，一行新账在那儿展开。
    - **戏剧性爆点**：保存瞬间屏幕中心炸开一个暖橙光点，涟漪荡开，新账落入列表。
33. **页面转场：三档可选**：原生左右滑 / 共享元素过渡（金额图标"飞"进详情）/ 上滑卡片式（像 iOS sheet）。
34. **余额数字滚动：三档可选**：瞬时跳变 / 滚动翻牌（老式计分牌，0.4 秒）/ 先缩后放（缩小、换值、弹回）。

### H. 功能尾巴（3 项）

35. **预算：要，但只有总额**。设一个「本月总预算」数字，统计页 / 首页显示剩多少 + 进度条。一个数，不拆分类。
36. **搜索 + 筛选都做**：流水页顶部搜索框——按备注搜；按分类 / 账户 / 金额区间 / 日期范围筛选。
37. **导出备份：CSV + 加密备份都要**。导出 CSV（Excel 能直接打开）；导出加密备份（换手机 / 重装时完整恢复）。

### I. 信息架构（1 项）

38. **页面清单**：首页（账本）→ 统计页（洞察）· 记账表单（完整字段）· 流水详情 · 账户管理 · 分类管理 · 设置 · 首开引导。四个层级，见 §3。

### J. 神罚旧资产去留（8 项）

39. **工时折算 / 惩罚评估全删**：work、punishment 相关逻辑（极罚/重罚/警告、工时折算、预算平衡提醒）不进入 2.0。账本只记账，不审判。
40. **自动记账不搬**：通知监听、待确认队列等自动检测能力不进入 2.0，纯手动记账。
41. **账单导入不搬**：微信 / 支付宝 / 银行 CSV 导入不进入 2.0。
42. **待还 / 目标 / 考勤全删**：debts、goals、attendance 模块不进入 2.0。不要大额提醒、不要还款日历。
43. **magisk 模块文件保留、不加载**：仓库里的 magisk/ 文件不删，但 v2 不再构建或加载它。
44. **v1 数据不迁移**：v1 归 v1，v2 从零开始记，不做数据迁移。
45. **v1 代码封存**：main 分支保留 v1 可运行状态；v2 在 feat/v2 独立开发，不共线演进。
46. **多币种要支持**：记账时选币种（默认人民币）。复杂度增加：分类与账户不绑定币种，交易带 currency 字段，统计与总余额按币种分开展示。

## 4. 页面规格

### 4.1 首页（账本）

- **结构（自上而下）**：余额卡 → 流水列表（按天分组）→ 悬浮 `+`（固定右下角）。
- **余额卡**：总余额为页面最大数字（如 `¥13,520`）；下方或旁边小字「本月支出 ¥3,480」；「今日支出 ¥86」一眼可见（小字但位置显眼）；右下角「统计」小图标 → 统计页。
- **流水**：按天分组；今天默认展开全部明细；非今天折叠为一行「11月15日 · 支出 ¥86」，点击展开 / 收起（带动画）。
- **流水行**（默认）：分类图标 + 备注 + 金额（支出 / 收入用颜色或正负区分）。开启开关后追加显示账户名、分类名小字。
- **日期导航**：顶部日期头可点（弹出日期选择）；侧边日期跳转条可快速滑到某天；打开 App 默认停今天。
- **异常态**：无流水时显示空态引导（"记下第一笔" + 指向悬浮 `+`）；有流水但当天无流水时显示「今天还没记」。

### 4.2 记账表单（完整表单）

- **字段顺序**：金额（大输入框，默认数字键盘）→ 方向（支出 / 收入，默认支出）→ 分类（支出两级选择器：先大类再小类；收入一级四类）→ 账户（默认记住上次用的）→ 日期（默认今天，可改过去）→ 备注（可选）。
- **转账**：方向选「转账」时变为：转出账户 → 转入账户 → 金额 → 日期 → 备注。同一界面内完成。
- **保存**：按选定的记账成功动效播放（三档之一），新账落入流水。
- **异常态**：金额为空 / 分类未选 / 转出转入账户相同 → 对应字段标红，不可保存；转账金额超过转出账户余额 → 提示但不阻止（允许负余额，见 §7）。

### 4.3 流水详情

- **展示**：全部字段 + 所属账户 + 余额影响。
- **操作**：编辑（回到表单，预填所有字段）；删除（二次确认后删除，余额自动重算）。
- **关联**：转账单展示转出 / 转入两腿的对应关系（互相跳转）。

### 4.4 统计页（洞察）

- **内容**：本月支出（与预算进度条一起）、分类占比图（两级下钻：点大类看小类）、今日 / 本周 / 本月 / 自定义区间切换、"该省哪"类洞察。
- **入口**：仅从首页余额卡右下角「统计」图标进入，返回回首页。

### 4.5 账户管理

- **列表**：每个账户一行——名称、图标、颜色、当前余额（流水自动算）。
- **操作**：新增账户；停用（藏起来，流水还在）；删除（仅空账户）；修改初始余额（即"对账修正"——修改的是初始余额基准，不直接改当前余额）。
- **转账入口**：从账户管理发起转账，或在记账表单选「转账」。

### 4.6 分类管理

- **支出**：两级列表。大类可增删改、排序；大类下小类可增删改；每个分类可改图标、颜色。删除有流水的分类 → 确认提示"旧流水将落进未分类"。
- **收入**：一级四类（工资 / 副业 / 报销 / 其他），同上可改。
- **默认清单**：出厂预置一套两级支出分类（吃饭 / 交通 / 购物 / 日用 / 娱乐 / 其他 + 各带小类）和收入四类，用户可全改。

### 4.7 设置

- **流水显示**：备注 / 账户 / 分类名三开关 + 实时预览示例行。
- **主题**：暗色（默认）/ 浅色。
- **动画**：记账成功动效、页面转场、余额数字滚动，各三档单选。
- **预算**：本月总预算金额输入。
- **导出**：导出 CSV；导出加密备份；从备份恢复。

### 4.8 首开引导

- 首次打开：欢迎 → 填三个默认账户的初始余额（可跳过）→ 进入首页。跳过则首页余额卡显示"去设初始余额"入口，引导补填。

## 5. 视觉规范

- **主题**：默认暗色（深色底、高对比），可选浅色。两套配色维护同一套布局。
- **主色**：暖橙 / 琥珀，用于点缀——悬浮 `+`、选中态、进度条、动效光点。
- **金额语义色**：支出 / 收入用不同颜色（暗色下暖橙支出、绿色收入之类，具体色值实现时定）。
- **分类体系**：每个分类有图标 + 颜色（用户可改），颜色用于统计图和流水行图标底。
- **质感**：暗色下有霓虹点缀感，但以"安静、清爽"为基调——点缀是亮点不是噪音。
- **圆角 / 间距 / 字重**：余额大数字用大号、细体（高对比）；分组日期头小号、灰阶；卡片圆角统一，实现时出具体 tokens。

## 6. 动画规格

- **全局**：按钮弹性、列表阻尼、折叠展开、图表生长（处处都有）。
- **三档设置项**（默认档实现时定，建议：记账成功=轻快收束，转场=原生左右滑，数字滚动=先缩后放）：
  - 记账成功：清爽回位 / 轻快收束 / 戏剧性爆点。
  - 页面转场：原生左右滑 / 共享元素过渡 / 上滑卡片式。
  - 余额数字滚动：瞬时跳变 / 滚动翻牌 / 先缩后放。
- **时长基准**：短动效 150–250ms，中动效 300–450ms，长动效（生长 / 爆点）≤ 600ms。宁可快，不可拖。

## 7. 数据需求（需求层，不含实现）

- **账户**：名称、图标、颜色、初始余额、启用 / 停用状态、创建时间。余额 = 初始 + 收入 − 支出（含转账进出），派生不落库。
- **交易（流水）**：类型（支出 / 收入 / 转账）、金额（精确到分）、币种（默认人民币，可切换）、分类（支出两级 / 收入一级；转账无分类）、账户（转账为转出 + 转入两个）、日期（可过去）、备注（可选）、创建 / 修改时间。
- **多币种**：分类与账户不绑定币种；每笔交易带 currency 字段；统计与总余额按币种分开展示（人民币与外币分列，不做自动汇率换算）。
- **转账**：一笔转账 = 转出腿 + 转入腿，两腿关联、互相跳转；转出账户减、转入账户加，所有账户总余额不变。
- **分类**：两级结构（支出）/ 一级（收入）；名称、图标、颜色、排序；删除后旧交易落「未分类」。
- **预算**：单值——本月总预算金额。
- **设置**：流水显示三开关、主题、动效三 × 三档、分类 / 账户数据、导出偏好。
- **允许负余额**：账户余额可以为负（信用卡等场景），只展示，不惩罚、不提醒。

## 8. 验收标准

1. 记一笔支出（¥50，微信）后，微信余额减少 ¥50，总余额减少 ¥50，首页今日支出 +¥50。
2. 记一笔收入（¥8000 工资，银行卡）后，银行卡余额 +¥8000。
3. 记一笔转账（银行卡 → 微信 ¥2000）后，银行卡 −2000、微信 +2000，**总余额不变**。
4. 修改 / 删除流水后，相关账户余额自动重算且与逐笔累加一致。
5. 新增账户、停用账户、删除空账户行为符合决策 13 / 14；对非空账户不出现删除按钮。
6. 删除分类后，其下流水落入「未分类」，统计单列，可手动重新分类。
7. 流水删除需要两次确认；编辑字段即时生效。
8. 日期可任意选过去，流水按所选日期落位，月统计归入对应月份。
9. 首页打开即见：总余额大数字、本月支出、今日支出；默认停今天；非今天分组默认折叠、点击展开。
10. 流水行默认显示图标 + 备注 + 金额；设置里三个开关（备注 / 账户 / 分类名）切换后首页立即生效。
11. 默认暗色主题；切浅色后全 App 一致切换，无漏页。
12. 记账成功动效、页面转场、余额数字滚动各有三档可选且切换即时生效。
13. 本月总预算设置后，统计页 / 首页显示剩余额度与进度条。
14. 搜索（备注）与筛选（分类 / 账户 / 金额区间 / 日期范围）组合可用。
15. 导出 CSV 可被 Excel 直接打开；导出加密备份可在干净安装中完整恢复全部数据。
16. 首开引导可填三账户初始余额，跳过后可后续补填。
17. 记账时可选择币种（默认人民币）；统计与总余额按币种分列展示。
